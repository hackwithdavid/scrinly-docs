title: "Caching"
description: "Opt into screenshot caching and understand the independent Style Guide cache."
---

Screenshot caching is off by default. Set `cache:true` to reuse an account-scoped stored result whose validated response-affecting options match.

Identity includes the target, viewport or device, format, quality, full-page mode, theme, interactions, cleanup controls, regions, storage provider and prefix, and return-location behavior. Headers, cookies, and customer-storage credentials participate only through an opaque HMAC fingerprint; their values are not stored in cache keys or entries.

The normal TTL is one hour and high-priority entries use five minutes. Entries missing a requested media URL, region crop, hash, projection, or extraction component are rejected as misses. `cache:false` always captures fresh and does not write the screenshot cache. Screenshot-cache hits retain normal screenshot and region pricing.

## Visual Style Guide cache

Successful Style Guides cache automatically for seven days. Identity includes the account, screenshot and crop hashes, deterministic projection, prompt/schema/vision versions, OpenAI host and model settings, credential mode, and a keyed BYOK fingerprint. Platform and BYOK entries never mix.

`styleGuide.regenerate:true` bypasses only this AI cache and replaces it after a successful generation. It does not turn screenshot caching on or off. Use `cache:false` plus regeneration to force both layers fresh.

Failed generations are never cached. Cache read/write failure is non-fatal to an otherwise successful capture or Style Guide.

---
title: "Quickstart"
description: "Capture your first Scrinly screenshot in five minutes."
---

Create an API key in the [Scrinly dashboard](https://app.scrinly.com), save it in a server-side environment variable, and make a request.

<Tip>
  Prefer to explore the options visually? [Try the Screenshot Playground](https://app.scrinly.com/#playground). Sign-in is required, and after authentication you will return directly to the Playground.
</Tip>

<CodeGroup>
```bash cURL
curl --get "https://api.scrinly.com/render/screenshot" \
  --header "Authorization: Bearer $SCRINLY_API_KEY" \
  --data-urlencode "url=https://example.com" \
  --data-urlencode "format=png" \
  --output screenshot.png
```

```javascript JavaScript
const response = await fetch("https://api.scrinly.com/render/screenshot", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.SCRINLY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://example.com",
    format: "png",
  }),
});

if (!response.ok) throw new Error(await response.text());
const image = Buffer.from(await response.arrayBuffer());
```

```python Python
import os
import requests

response = requests.post(
    "https://api.scrinly.com/render/screenshot",
    headers={"Authorization": f"Bearer {os.environ['SCRINLY_API_KEY']}"},
    json={"url": "https://example.com", "format": "png"},
)
response.raise_for_status()
open("screenshot.png", "wb").write(response.content)
```
</CodeGroup>

The response is binary because storage is off. To receive JSON and a direct provider URL, add `store:true` and a `storage_path`:

```json
{
  "url": "https://example.com",
  "format": "jpg",
  "fullPage": true,
  "store": true,
  "storage_path": "screenshots"
}
```

---
title: "API reference"
description: "The focused, unversioned Scrinly screenshot contract."
---

The production base URL is:

```text
https://api.scrinly.com
```

All operations use `Authorization: Bearer $SCRINLY_API_KEY`. Screenshot Visual Style Guide calls may additionally carry `X-Scrinly-Provider-API-Key`; no other operation accepts that header.

Screenshot responses are binary unless storage or an add-on requires JSON. Stored screenshots, region crops, and diff images return direct B2, S3, or R2 URLs. Async requests return `202`; batches may return `207 Multi-Status`; component-level screenshot failures may return a usable HTTP `200` partial result.

The endpoint pages in this section are generated from the checked OpenAPI 3.1 contract. Only public screenshot, batch, diff, monitoring, recipient, status, and usage operations are included.

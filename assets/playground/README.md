# Playground documentation screenshots

Actual browser screenshots of the current dashboard UI, generated by
`browser-cluster-cf/scripts/capture-playground-docs.mjs` under Node 22.22.2.

The session is isolated and all requests are intercepted. It displays the real,
previously captured Tailwind CSS screenshot and region crops from
`home/public/data/regions-demo.json`, after SHA-256 validation. The original
historical regions-v1 labels are retained. Tailwind CSS is not affiliated with Scrinly.

The demo account, `scr_documentation_demo` reference, and expiry are UI fixtures,
not production account records. No keys, cookies, or production storage URLs are
shown. No captures, billable transformations, or fake output results are generated.
The Transform image illustrates configuration, not successful execution.
